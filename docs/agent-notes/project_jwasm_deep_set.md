As of 2026-06-17, the **assembly migration is complete**: `make -k all` (jwasm is now the Makefile default -- see [[project_jwasm_make_invocation]]) produces **0 assembler errors** tree-wide. All of the Jun-17 deep-set targets were cleared source-side -- WCHSTRA, SYS1, VAR, PRINT_TM, DEBMES, F_CLOSE, EMMP, TDATA, E2BINIT, MSFOR, and **GSHARE/GSHARE2**.

Notably GSHARE/GSHARE2 were NOT a jwasm engine gap (the prior "defer-to-upstream A2080/A2082 conditional-segment" diagnosis was wrong). Root cause: `IF NOT INSTALLED` with `Installed = TRUE` -- jwasm evaluates `NOT <truthy>` as a wide truthy value (the documented NOT-TRUE bug, cf MSDOS.SYS #53), so the wrong IF branch ran and the SHARE segment never opened. Fix: `IF INSTALLED EQ 0`. General lesson: any `IF NOT <flag>` where the flag is TRUE/0FFFFh is suspect under jwasm; rewrite as `IF <flag> EQ 0`.
